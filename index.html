Why a deck?

Long prose explanations get skimmed and the logic gets lost. A deck forces the opposite discipline.

1

One message per slide

One slide = one screen. If it doesn't fit, you split it — so each idea lands on its own.

2

Diagrams are the content

Flowcharts, sequence diagrams, and before/after pairs carry the load. Prose shrinks into small WHY / CAUTION / FACTS panels.

3

Flip, don't scroll

Arrow keys, Space, on-screen buttons, touch swipe, and dots. No endless vertical scroll.

How it works

No framework, no build. The whole deck is one self-contained HTML file.

Copy the template

Grab TEMPLATE.html — a dark-theme deck skeleton with eight slide types and the navigation wired in.

Fill the slides

Replace the {{...}} placeholders, add or remove <section> blocks. The nav counts them automatically.

Open it

Double-click the file. Mermaid renders, scroll-snap navigation just works. Ship the single file anywhere.

Install

Two ways to use it.

A As a Claude Code skill

git clone https://github.com/cskwork/mermaid-slide-deck.git \
  ~/.claude/skills/mermaid-slide-deck

Then ask: "explain this logic as slides / as a deck / with diagrams." Korean triggers work too — 슬라이드로 설명, 다이어그램으로 보여줘.

B As a plain HTML template

curl -O https://raw.githubusercontent.com/\
cskwork/mermaid-slide-deck/main/TEMPLATE.html
# edit the {{...}} placeholders, then open it

No Node, no bundler. Works offline except the Mermaid CDN script.
